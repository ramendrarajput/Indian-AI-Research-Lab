# Purpose

Pattern Taxonomy is the classification framework of Project BRAHMA.

Its objective is to systematically organize every recurring pattern discovered across mathematics, physics, biology, neuroscience, artificial intelligence, music, language, cognition, and the universe.

Instead of studying patterns independently, this document seeks to build a universal classification system capable of describing relationships between seemingly unrelated phenomena.

---

# Scope

This document focuses exclusively on the classification of patterns.

It does not attempt to explain why patterns exist.

Instead, it provides a structured vocabulary through which future research can describe, compare, and connect patterns across multiple disciplines.

---

# Core Research Questions

- What is a pattern?
- How can patterns be classified?
- Are there universal categories of patterns?
- Can different scientific disciplines share identical pattern structures?
- Can pattern evolution be mathematically represented?
- Is intelligence fundamentally a pattern classification process?

# Project BRAHMA Pattern Taxonomy

## A Classification Framework for Universal Patterns

> **Version 1.0**

Project BRAHMA proposes that intelligence cannot be understood by studying isolated objects alone.

Instead, intelligence emerges through interactions among recurring patterns.

This document provides the first official taxonomy of patterns used throughout Project BRAHMA.

---

# What is a Pattern?

A pattern is

> **A recurring organization, relationship or behaviour that appears across observations.**

Patterns may exist in

* mathematics
* nature
* biology
* information
* intelligence
* societies
* artificial systems

---

# Pattern Discovery Workflow

Every newly proposed pattern follows the same process.

```text
Observation

↓

Repeated Observation

↓

Pattern Candidate

↓

Classification

↓

Mathematical Description

↓

Experimental Testing

↓

Scientific Acceptance
```

Project BRAHMA never classifies speculation as established knowledge.

---

# Pattern Quality Levels

Level A

Established across multiple scientific disciplines.

Level B

Supported by significant evidence but still actively researched.

Level C

Reasonable working hypothesis.

Level D

Speculative idea requiring evidence.

---

# Research Principles

A pattern should satisfy as many of the following as possible.

* Repeatable
* Observable
* Measurable
* Mathematically describable
* Computationally representable
* Experimentally testable
* Cross-disciplinary

The greater the number of satisfied criteria,

the stronger the candidate pattern.

---

# Long-Term Objective

Project BRAHMA seeks to determine whether a small number of fundamental organizational patterns may explain a wide variety of apparently unrelated phenomena.

Whether such universal principles exist remains an open scientific question.
