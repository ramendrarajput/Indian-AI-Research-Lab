# 🌍 What is Project BRAHMA?

**Project BRAHMA** is an open scientific initiative dedicated to building a **Universal Intelligence Architecture** capable of supporting the future evolution of Artificial Intelligence, Scientific Research, Cognitive Systems, Robotics, Physics, Mathematics, Biology, Quantum Computing, and every future intelligent discipline.

Unlike conventional AI projects that focus on building a single chatbot, model, or application, Project BRAHMA is designed as a **Universal Cognitive Operating System**—a long-term engineering and research foundation upon which intelligent systems can continuously evolve.

Project BRAHMA is being developed under the **Indian AI Research Lab**, where scientific research, software engineering, and philosophical inquiry converge into a single architectural vision.

Rather than asking:

> **"How do we build another AI application?"**

Project BRAHMA asks a much larger question:

> **"How should intelligence itself be architected?"**

Every module, laboratory, runtime component, document, and engineering decision inside this repository contributes toward answering that question.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/ramendrarajput/Indian-AI-Research-Lab.git

cd Indian-AI-Research-Lab
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Project BRAHMA

```bash
streamlit run app.py
```

The runtime will initialize the engineering framework before launching the user interface.

Future versions will display the complete runtime boot sequence visually inside the application itself.
